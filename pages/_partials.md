# Sub-page convention

All sub-pages reuse:
- The same `<head>` block and Tailwind config from `index.html`.
- The header/nav and footer markup verbatim (these will become WordPress
  template parts: `header.php` and `footer.php`).

Only the `<main>` content changes per page. Below pages are intentionally
focused — they each ship one clear job-to-be-done so a visitor never lands
on a "thin" content page.
